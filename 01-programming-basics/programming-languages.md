# Programming Languages

4. How does a computer understand `if`, `for`, `while`, and functions?

The language defines the meaning and grammar of these constructs. A compiler or interpreter parses them into an internal representation and ultimately machine operations such as comparisons, jumps, and calls.

5. Who decides what a programming language can do?

Language designers propose its rules and features; standards bodies or language communities may formalize them. Implementers build compilers and runtimes, and programmers influence which features prove useful in practice.

6. Why are there hundreds of programming languages?

Languages are designed for different trade-offs, eras, hardware, and communities. New ones also experiment with safer, simpler, faster, or more expressive ways to solve problems; many overlap rather than being strictly necessary.

7. Why do we need Python, Java, JavaScript, C, C++, Go, Rust, and others?

Each has strengths and an ecosystem: JavaScript is built into browsers, Python is approachable and has strong data tools, C offers low-level control, and Rust emphasizes memory safety without a garbage collector. The best choice depends on the task, team, platform, and existing software.

8. What makes one programming language different from another?

Languages differ in syntax, type systems, runtime behavior, memory management, concurrency tools, performance, and available libraries. These choices affect how code is written, checked, executed, and maintained.
