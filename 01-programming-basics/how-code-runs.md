# How Code Runs

9. Why does a programming language need a compiler or interpreter?

Processors execute machine instructions, not most programmers' source code directly. A compiler translates code ahead of time, while an interpreter or runtime processes it as the program runs; some languages use a mix of both.

10. What actually happens when you run a program?

The operating system starts a process, loads the program and its dependencies, and gives it resources. The language runtime executes its instructions, communicates with the OS as needed, and eventually returns an exit status or is stopped after an error.
