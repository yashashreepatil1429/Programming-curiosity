# JavaScript

82. Why is JavaScript used in browsers?

Browsers include JavaScript engines and web APIs that let scripts respond to user actions, change page content, and communicate with servers. It became the standard scripting language of the web, though modern browsers also execute other technologies such as WebAssembly.

83. Why is Node.js able to run JavaScript on servers?

Node.js embeds the V8 JavaScript engine and supplies server-oriented APIs for files, networking, and operating-system access. This lets JavaScript run outside a browser; its event-driven I/O model is useful for many network services, but CPU-heavy tasks may need workers or separate services.
