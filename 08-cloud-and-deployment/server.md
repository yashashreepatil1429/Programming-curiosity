# Servers

91. Where does your application actually run after deployment?

It runs on computing infrastructure such as a physical machine, virtual machine, container, or managed serverless platform in a data centre. A domain name and routing configuration direct clients to it; the data centre may be operated by your organization or a cloud provider.

92. What happens when one user uses your application?

The user's device runs the client interface and sends requests over a network. Server-side code handles each request, may read or update a database, and sends a response; even with one user, authentication, errors, and data persistence still matter.

95. What is a server?

A server is software that provides a service to clients; the term also informally means the computer running that software. A single machine can host many server programs, and one service can run across many machines.
