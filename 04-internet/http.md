# HTTP

46. What is HTTP?

HTTP is a request-response protocol used to transfer web resources and API data. It defines methods, headers, status codes, and message formats; HTTPS is HTTP carried over a protected TLS connection.

48. What happens when you click a button on a website?

The browser runs event-handling code associated with the button. It may update the page locally, validate input, or send a request to a server; the server's response can update data or cause the page to display a result or error.

49. How does your request travel thousands of kilometres?

The device divides network data into packets and sends them through local networks, routers, and internet service providers. Routers forward packets toward the destination using IP routing; different packets can take different paths, and the receiving protocols reassemble the data.

50. How does the server know where to send the response?

The connection and network protocols provide return-address information, and the server replies on that connection. Application-level information such as a URL path, cookies, or a request identifier determines which resource or operation the response should represent.
