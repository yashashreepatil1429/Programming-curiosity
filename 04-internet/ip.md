# IP Addresses and Ports

44. What is an IP address?

An IP address identifies a network interface or endpoint for routing packets using IPv4 or IPv6. Public and private addresses serve different roles, and addresses can be shared, translated, or reassigned rather than permanently identifying one person or machine.

45. Why do we need ports?

An IP address gets traffic to a host; a port number helps deliver it to the right service or application on that host. For example, web servers commonly accept HTTP on port 80 and HTTPS on 443, though deployments can use other ports.
