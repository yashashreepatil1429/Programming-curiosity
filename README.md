# Programming Curiosity

This repository is about understanding the why, what, how, where, when, who, and what-if behind the technology we use every day. Every question is an opportunity to go one level deeper. Don't just learn code; understand what happens behind the code.

## Programming Curiosity Challenge

The purpose of this challenge is to make you ask: **“But how does this actually work?”**

Don't search for the answers immediately. Pick questions, discuss them with your team, make your own assumptions, and then investigate the real answers.

### Ask seven questions whenever you learn something

- **WHY?**
- **WHAT?**
- **HOW?**
- **WHERE?**
- **WHEN?**
- **WHO?**
- **WHAT IF?**

Use these questions to look at a topic from several angles. For example, when learning MongoDB, don't stop at “I learned MongoDB.” Ask what it is, why we use it, how it stores data, where the data lives, when to choose it, who uses it, and what happens if it goes down.

A good programmer doesn't just learn answers. A good programmer develops better questions.
