# NoSQL

70. What is the difference between SQL and NoSQL?

SQL databases commonly organize data in related tables and query it with SQL, often enforcing a defined schema and strong transaction features. “NoSQL” covers several non-relational models—document, key-value, graph, and wide-column—with different schemas and scaling trade-offs. Neither category is universally better; choose for the data, query patterns, consistency needs, and operations you require.
