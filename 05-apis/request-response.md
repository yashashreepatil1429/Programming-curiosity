# Requests and Responses

54. What is a request?

A request is a message asking a service to perform an operation or provide a resource. An HTTP request includes a method and target, and may include headers and a body.

55. What is a response?

A response is the service's reply, containing an outcome such as a status code and any requested data or error details. A response can succeed, report invalid input, require authentication, or indicate a server problem.

56. Why do APIs commonly use JSON?

JSON is readable, compact, and supported by most programming languages, making it convenient for exchanging structured data. It has fewer data types than many languages, so APIs must define how values such as dates, large numbers, and missing fields are represented.
